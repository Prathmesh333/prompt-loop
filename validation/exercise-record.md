## Task contract: repair

Contract version: 1

Exercise request: Repair `dedupe(values)` so that it returns a list containing the first occurrence of each equal value. Preserve input order. Support integers, strings, lists, and dictionaries. Do not mutate the input or copy the retained values. Use only the Python standard library.

This request is a controlled validation fixture derived from the documented example. It is not an additional user task.

| Identifier | Required acceptance condition | Verification |
|---|---|---|
| C1 | Return the expected first occurrences in order | Empty, integer-order, and string checks |
| C2 | Support unhashable values and mixed input | List, dictionary, and mixed checks |
| C3 | Preserve input and retained object identity | Input-preservation and identity checks |
| C4 | Supply a Python function without external dependencies | Inspect the candidate source and run the checker |

Limits: Eight execution attempts, eight verification rounds, and three consecutive attempts without improvement.

Initial artifact: `fixtures/dedupe_seed.py`. The defective artifact was seeded deliberately before the exercise. It was not generated by a separate model or by this skill.

Planned verification round 1: Run all eight acceptance checks through `check_candidate.py`. Capture the report and the candidate hash. No execution attempt is consumed by this initial check.

Observed round 1: Two of eight checks passed. The integer-order check failed. Lists and dictionaries raised `TypeError`, which also prevented the mixed-input and identity checks from passing. See [the initial evidence](reports/repair-before.json).

Decision: Keep the request and criteria unchanged. The set-based implementation violates C1 and C2 and cannot establish C3. A targeted correction is available within the limits.
